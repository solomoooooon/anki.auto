# anki.auto Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the approved Windows Chrome capture extension and combined Anki browser reviewer.

**Architecture:** TypeScript extension, Python loopback backend, and one bundled Anki add-on. The backend runs a subscription-authenticated Codex worker; the add-on owns collection operations and native scheduling. All sources and distributions remain in this folder.

**Tech Stack:** Python 3.12+ standard library, Anki 25.09.5/native scheduler, TypeScript/esbuild, PDF.js, Tesseract.js, Node's test runner and Python unittest.

**Spec:** `docs/superpowers/specs/2026-11-09-anki-auto-design.md`

## Global Constraints

- Windows only; local, personal use.
- A supplied custom definition skips the model/dictionary call.
- Search for near matches in the destination deck only.
- Screenshots only supply text; they never appear on cards.
- Anki determines scheduling; never write review logs or scheduling fields directly.
- One vocabulary card plus an optional sibling example card: English example sentence front, French translation back.
- ChatGPT subscription authentication only; no paid API fallback.
- Sources and distributables stay under `anki.auto`; runtime secrets remain per-installation.

## Review Focus

- Changing a deck/term after duplicate confirmation must invalidate the acknowledgment (Task 1/3).
- Lost responses or restart after adding a note must not duplicate either sibling card (Task 2/3).
- Parent deck budgets and overlapping selected decks must not increase daily allowances (Task 2).
- Word capture inside frames, PDF pages, or near a viewport edge must preserve the selection and retain drafts (Task 4).
- Held keyboard keys, focused controls, editing, and stale browser tabs must not rate the next/wrong card (Task 2/5).

## Files and interfaces

- `anki_auto/contracts.py`: capture validation, response schema and errors; shared by backend/add-on via packaged copies.
- `anki_auto/matching.py`: pure local fuzzy search and collection-content fingerprint.
- `anki_auto/generator.py`: Codex subprocess boundary, schema, cache-key inputs.
- `anki_auto/backend.py`, `anki_auto/store.py`: authenticated HTTP API, jobs/cache and bridge client.
- `anki_addon/core.py`: `AnkiService(col, profile)`, `dispatch(action, payload) -> dict`.
- `anki_addon/review.py`: `ReviewSession.start(deck_ids)`, `current()`, `act(payload)` using native states.
- `anki_addon/__init__.py`: authenticated loopback server, main-thread dispatch and Anki hooks.
- `extension/src/{background,content,capture,review,settings,pdf,ocr,api,shortcuts}.ts`, `extension/src/style.css`, HTML pages and manifest.
- `scripts/{setup,start,install-addon,package}.ps1`, `scripts/build.mjs`, root `package.json`, `README.md`.
- `tests/`: Python behavior/integration tests; `extension/tests/`: focused browser-independent keyboard tests.
